# Local typefaces

Downloaded 30 October 2026 from the Google Fonts service. These are the same DM Sans and Manrope families already used by this prototype, saved locally so the shelf has no font-network dependency offline. The variable Latin and Latin-ext WOFF2 subsets support the interface's weight ranges.

- DM Sans v17: `https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2` and `https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu6-K6h9Q.woff2`.
- Manrope v23: `https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2` and `https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggmxSuXd.woff2`.
- Source stylesheet: `https://fonts.googleapis.com/css2?family=DM+Sans:wght@100..1000&family=Manrope:wght@200..800&display=swap`.
- Open Font License files are retained as `DM-Sans-OFL.txt` and `Manrope-OFL.txt`, sourced from the corresponding `google/fonts` family folders.

Latin/Latin-ext are the interface's bundled font coverage; other characters use the existing system fallback. Printed card surfaces remain separate image assets.
